### 변경 사항 요약
> 그룹분석 화면의 배치 이력 로드를 명시적 버튼 클릭으로만 동작하도록 바꾸고, 배치별 로드 상태·안내 메시지 위치를 정리했다.

### 상세 변경 사항
**1. 배치 로드 게이팅**
- 페이지 진입 시 조용히 이뤄지던 "전체 배치" 자동 로드를 완전히 제거
- 배치 이력에서 배치를 체크하고 "선택된 배치 로드"를 명시적으로 눌러야만 데이터가 반영됨
- 로드 전에는 매트릭스/제출용/그래프 저장 버튼이 모두 비활성 상태로 유지됨
- 체크박스 0개인 상태로 "선택된 배치 로드"를 눌러도 더 이상 전체 배치로 대체 로드되지 않음(경고만 표시)

**2. 배치별 로드 상태 표시**
- 배치 이력 표에 "상태"(로드됨/로드 필요) 열 신설
- 로드 결과 메시지("N명 직원, N개 배치, N개 평가 로드됨")를 로드 버튼 바로 옆에 표시

**3. 안내/상태 메시지 정리**
- 산발적으로 표시되던 안내 문구를 한 줄로 통합해 카드 레이아웃이 흔들리지 않도록 개선

**4. 표 행 클릭 토글**
- 배치 이력 표의 행에서 체크박스·편집·삭제 버튼이 아닌 곳을 클릭해도 체크박스가 토글됨

**5. 영향받는 페이지**
- 그룹분석(`/perspective_test`)

### 버그 수정
- 배치 이력을 로드하지 않았는데도 매트릭스/제출용/그래프 저장 버튼이 동작하던 문제
- 체크박스 0개 상태에서 "선택된 배치 로드"를 눌러도 전체 배치로 조용히 대체 로드되던 문제
- 안내 문구 칸이 텍스트 없을 때 줄 높이가 붕괴해 카드 높이가 계속 바뀌던 문제

### 개선 사항
- 배치별 로드 상태를 표에서 시각적으로 확인 가능
- 로드 실행 위치(버튼)와 결과 표시 위치를 근접시킴
- 배치 이력 표 행 클릭으로 체크박스 토글 가능
