# 33. 보고서 세트 분할 · 고지 도달 검사 (INS-9 · INS-12)

> [30-report-insight-structure.md](30-report-insight-structure.md) 의 **INS-9(주제별 분할)·INS-12(고지 도달)** 상세다. 조항 표는 30 이 정본이고, **분할 임계·세트 구성·도달 검사 절차는 여기가 정본**이다.
>
> 분할은 문서를 나누는 일이 아니라 **독자를 나누는 일**이다. 나누는 규칙(§1·§2)만 있고 나눈 뒤 **무엇이 누구에게 닿는지 확인하는 규칙**(§3)이 없으면, 고지는 문서에 존재하면서 정작 그 고지를 필요로 하는 독자에게는 도달하지 않는다.

---

## 1. 분할 임계 (INS-9)

**아래 중 둘 이상**에 걸리면 단일 문서를 유지하지 않는다.

| 신호 | 임계 |
|---|---|
| 본문 분량 | 600줄 초과 |
| 장(章) 수 | 8개 초과 |
| 독자 종류 | 결재자·실무자·기술 검토자가 한 문서를 공유 |
| 갱신 주기 | 절마다 다름(수치는 분기, 절차는 연 1회) |

## 2. 세트 구성 (INS-9)

주제별 문서 N개 + **안내서 1장**. 안내서는 규칙이 아니라 **라우팅**만 담는다.

| 안내서에 담는 것 | 담지 않는 것 |
|---|---|
| 「독자가 묻는 질문 → 볼 문서」 표 | 각 문서의 내용 요약(두 벌이 된다) |
| 문서 간 선후·의존 관계(무엇을 먼저 읽나) | 수치 |
| 각 문서의 갱신 책임·주기 | 이력 |

- 같은 수치를 두 문서에서 계산해 적지 않는다. **한 문서를 정본으로 정하고 나머지는 인용**한다.
- 분할은 사용자 결정 사항이다 — 임계에 걸렸다는 사실과 분할안을 **보고하고 승인받은 뒤** 나눈다.

---

## 3. 고지 도달 검사 (INS-12 — 분할 직후 1회, 수치·한계가 바뀔 때마다 재실행)

**실사고** — 안내서가 「결재자는 결과 문서 하나로 결과 판단이 됩니다」라고 안내한 대외 제출 세트에서, 성능 근거로 쓰인 한 수치의 **근거 소실 사실이 한계 문서에만** 적혔다. 고지 문장 자체는 정확했으나 결재자가 읽는 결과 문서에는 한 줄도 없었고, 그 수치는 결과 문서에서 계속 성능 근거로 인용됐다.

각 한계·제약 고지마다 아래 표를 채운다. **판단하는 독자에게 닿지 않는 고지는 고지가 아니다.**

| 한계·제약 고지 | 적힌 문서 | 그 고지가 필요한 독자 | 그 독자가 읽는 문서 | 도달 |
|---|---|---|---|---|
| (예) 수치 A 의 근거 소실 | 한계·미결 문서 | 결재자 | 결과 문서 | ✗ |

- 「도달」이 ✗ 인 행이 하나라도 있으면 **분할이 끝난 것이 아니다.** 해소는 둘 중 하나다 — ⑴ 그 독자가 읽는 문서에 고지를 **싣는다**(포인터 1줄이 아니라 판단에 필요한 만큼) ⑵ 안내서의 「이 문서만 읽으면 판단이 됩니다」 안내를 **철회**하고 함께 읽을 문서를 지정한다.
- **수치의 결격 사유는 그 수치와 같은 자리에 둔다.** 다른 문서 링크로 대체하지 않는다 — 독자는 링크를 따라가지 않은 채 수치를 인용한다.
- **INS-8 과의 경계** — 별도 문서로 빼는 것은 경위·해소 경로·이력이고, **그 수치를 근거로 쓸 수 있는지 여부**는 수치 옆에 남는다.
- 재현 불가가 확정된 수치는 도달 검사 이전에 **근거에서 빠진다** → [17-hallucination-prevention/09-data-absence.md](17-hallucination-prevention/09-data-absence.md) ABS-9.

## 4. 자가검사 ([30](30-report-insight-structure.md) §7 항목 9의 세부)

| # | 확인 | 센 명령 (결과 건수를 보고에 적는다) |
|---|------|------|
| 9-1 | 고지 도달 표에 **✗ 0건** | §3 표를 파일로 남기고 `grep -c "✗" <도달표>` → **0** 이어야 한다 |
| 9-2 | 「이 문서 하나로 판단이 된다」고 안내한 문서에 **그 판단에 영향을 주는 한계가 전부 수록** | ⑴ `grep -n "하나로\|만 읽으면\|판단이 됩니다" <안내서>` 로 단독 판단이 안내된 문서를 특정 ⑵ 각 한계의 핵심어를 정해 `grep -c "<핵심어>" <그 문서>` → **1 이상**. 0 이면 미도달 |
| 9-3 | 근거로 제시한 수치 중 **결격 사유가 다른 문서에만 있는 것 0건** | 수치 문자열마다 `grep -rn "<수치>" <세트 폴더>` 로 인용처를 전수 열거하고, 결격 사유 핵심어가 **같은 문서·같은 절**에 있는지 각 인용처에서 확인 |

숫자를 적을 때는 **센 명령을 함께 적는다.** 눈으로 센 값은 보고하지 않는다.
