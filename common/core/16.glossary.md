# 16. 용어 사전 (Glossary)

> ⚠️ **이 문서는 에밀리 프로젝트 전반에서 공통으로 사용하는 게임 용어의 정의를 담당합니다.**
> 코드/문서/작업 지시에서 용어가 혼용될 때 이 문서의 정의를 기준으로 사용한다.

---

## 게임 시간 단위

| 용어 | 정의 |
|------|------|
| **턴 (Turn)** | 일자(오전/오후) 또는 스케줄로 인해 작업(활동 실행)이 진행되는 게임 시간 단위. 오전·오후 각각 1턴, 14턴(7일×2)=1주차. 활동 실행·주차 전환이 턴 진행이며 **자동 저장 트리거**이다. |
| **오전/오후 (AM/PM)** | 하루의 시간대 단위. 각 시간대가 1턴에 해당한다. |
| **주차 (Week)** | 7일(요일별 오전/오후) 스케줄 진행 단위. 14턴 완료 시 자동으로 다음 주로 전환되며 `user_state.week_number`로 영속화된다. |

## 스케줄 시스템

| 용어 | 정의 |
|------|------|
| **활동 (Activity)** | 오전/오후에 배치·실행되는 행동 (청소·산책·독서 등). 실행 시 스탯 변화 등 효과가 적용된다. |
| **스케줄 (Schedule)** | 요일별 오전/오후 활동 배치표. 현재 시간대의 활동 카드로 구성된다. |
| **주간 계획 (Weekly Plan)** | 14개 슬롯(월 AM~일 PM)의 활동 배치·실행 상태. `user_state.weekly_plan`으로 영속화된다. |
| **슬롯 (Slot)** | 주간 계획의 시간 단위(총 14개). 저장 슬롯의 하위 개념으로도 사용된다. |
| **프론티어 (Frontier)** | 다음 실행 대상이 되는 가장 이른 미실행 슬롯. 실행 버튼은 현재 탭이 frontier 시간대와 일치할 때만 활성화된다. |

## 저장 시스템

| 용어 | 정의 |
|------|------|
| **자동 저장** | 턴 진행(활동 실행·주차 전환) 성공 시 자동 슬롯(id 0)에 최신 상태 스냅샷을 저장하는 것. 사용자가 개입하지 않는다. |
| **저장 슬롯** | 수동 슬롯(3개, 사용자 저장) + 자동 저장 슬롯(1개, 시스템 전용). 자동 슬롯은 수동 저장·삭제가 불가능하다. |
