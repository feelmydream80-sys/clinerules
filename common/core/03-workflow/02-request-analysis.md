# 요청 분석 규칙

**MANDATORY - 모든 작업에 적용**

- 사용자 요청을 받으면 다음을 먼저 확인:
  1. 이 요청이 "새 기능 추가"인가 "기존 기능 수정/버그 수정"인가?
  2. 에러 메시지가 있는가? 있다면 전체 맥락 확인
  3. 기존에 동작하던 것이 안 되는 것인가, 처음 만드는 것인가?
  4. **요청 대상이 명확한가?** (어떤 파일, 어떤 폴더, 어떤 저장소인지)
- 확인 없이 코드 수정 시작 금지
- 문제를 파악하면 "이 파일들을 확인하세요"라는 구체적 안내 제공
- **요청 범위 외 변경 금지**: 요청에 없는 속성·동작(예: `sticky`, 애니메이션, 정렬) 수정 금지. 필요하면 먼저 제안하고 승인 후 진행
- **모호한 UI 지칭은 확인**: "메인 월드 흐름도" 같은 요소명은 화면상 어느 컴포넌트인지 반드시 질문하여 확정 (예: `adventure-editor.tsx`의 흐름도 카드)
